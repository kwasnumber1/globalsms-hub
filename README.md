# GlobalSMS Hub

A React website with Netlify serverless demo functions.

## Build

npm run build

## Build settings

Build command: npm run build

Publish directory: dist

Functions directory: netlify/functions

## Demo endpoints

- /.netlify/functions/health
- /.netlify/functions/allocate
- /.netlify/functions/inbox
- /.netlify/functions/release

## Important

This project uses sample data only.

It does not rent real numbers, receive real SMS,
or provide real OTP messages.

Real SMS requires an authorized provider API,
secure server-side configuration, and persistent storage.

No payment processing is included.
